DAY 20 OF CSS: TRANSFORM & TRANSITION

PART 1: TRANSFORM

transform changes how an element looks (turn, resize, slant) without disturbing the layout of the elements around it.

Syntax:
  selector {
    transform: function(value);
  }

1) ROTATE

Turns the element around its origin point.
Positive value = clockwise, negative value = anti-clockwise.

  transform: rotate(45deg);
  transform: rotate(-90deg);
  transform: rotate(0.5turn);     /* 180deg */

Units: deg, turn, rad, grad

Axis versions (3D):
  transform: rotateX(45deg);
  transform: rotateY(45deg);
  transform: rotateZ(45deg);      /* same as rotate() */

Example:
  .box:hover {
    transform: rotate(360deg);
  }


2) SCALE

Makes the element bigger or smaller.
1 = original size, above 1 = bigger, below 1 = smaller.

  transform: scale(1.5);          /* 150% width and height */
  transform: scale(2, 0.5);       /* x, y */
  transform: scaleX(2);           /* only width */
  transform: scaleY(0.5);         /* only height */

Example:
  .card:hover {
    transform: scale(1.1);
  }


3) SKEW

Slants the element along the X and/or Y axis.

  transform: skew(20deg, 10deg);  /* x, y */
  transform: skewX(20deg);
  transform: skewY(10deg);

Example:
  .banner {
    transform: skewX(-15deg);
  }


4) TRANSFORM-ORIGIN

Sets the fixed point (pivot) around which the transform happens.
Default is the center: 50% 50%.

  transform-origin: center;
  transform-origin: top left;
  transform-origin: bottom right;
  transform-origin: 0 0;
  transform-origin: 100% 50%;
  transform-origin: 20px 40px;

Example: rotate from the top-left corner instead of the center
  .box {
    transform-origin: top left;
    transform: rotate(45deg);
  }


PART 2: transition

A transition makes a property change smoothly over time instead of snapping instantly. 
It needs a trigger such as :hover, :focus, :active or a class change.


1) TRANSITION-PROPERTY

Which CSS property should animate.

  transition-property: all;           /* every animatable property */
  transition-property: background-color;
  transition-property: transform;
  transition-property: width, opacity;    /* multiple, comma-separated */
  transition-property: none;


2) TRANSITION-DURATION

How long the transition takes. Use s or ms. Default is 0s (no animation).

  transition-duration: 0.5s;
  transition-duration: 300ms;
  transition-duration: 1s, 2s;        /* one per property */


3) TRANSITION-TIMING-FUNCTION

The speed curve of the transition.

  linear         same speed from start to end
  ease           slow start, fast middle, slow end (default)
  ease-in        slow start
  ease-out       slow end
  ease-in-out    slow start and slow end
  steps(n)       jumps in n steps instead of smooth
  cubic-bezier(x1, y1, x2, y2)    custom curve

  transition-timing-function: ease-in-out;
  transition-timing-function: cubic-bezier(0.68, -0.55, 0.27, 1.55);


4) TRANSITION-DELAY

How long to wait before the transition starts. Default is 0s.

  transition-delay: 0.5s;
  transition-delay: 200ms;


SHORTHAND

  transition: property duration timing-function delay;

  transition: transform 0.5s ease-in-out 0.2s;
  transition: all 0.3s ease;
  transition: transform 0.3s, opacity 0.5s;     /* multiple */

Rules: the first time value is the duration, the second is the delay.
