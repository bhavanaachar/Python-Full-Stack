ADVANCED FUNCTION CONCEPTS
Topics:
1. Positional arguments
2. Keyword arguments
3. Default arguments
4. Variable-length arguments (*args)
5. Keyword variable-length arguments (**kwargs)
6. Return statement
7. Functions returning multiple values

QUICK TERMS
-----------
- Parameter : the variable name in the function definition.
- Argument  : the actual value you pass when calling the function.

    def greet(name):        # "name" is a parameter
        print("Hello", name)

    greet("Asha")           # "Asha" is an argument


1. POSITIONAL ARGUMENTS
- Values are matched to parameters BY POSITION (order matters).
- The number of arguments must match the number of parameters, otherwise Python raises a TypeError.

Example:
    def student(name, age, city):
        print(name, age, city)

    student("Ravi", 20, "Bengaluru")
    # Output: Ravi 20 Bengaluru

    student(20, "Ravi", "Bengaluru")
    # Output: 20 Ravi Bengaluru   (wrong order, wrong meaning)

    student("Ravi", 20)
    # TypeError: missing 1 required positional argument: 'city'

2. KEYWORD ARGUMENTS
- You pass values using parameter_name=value.
- Order does NOT matter.
- Makes calls easier to read.
- Positional arguments must come BEFORE keyword arguments in a call.

Example:
    def student(name, age, city):
        print(name, age, city)

    student(age=20, city="Bengaluru", name="Ravi")
    # Output: Ravi 20 Bengaluru

    student("Ravi", city="Bengaluru", age=20)    # mixing is fine
    # student(name="Ravi", 20, "Bengaluru")      # ERROR: positional after keyword


3. DEFAULT ARGUMENTS
- A parameter can have a default value, used when the caller gives none.
- Parameters with defaults must come AFTER parameters without defaults.

Example:
    def greet(name, message="Hello"):
        print(message, name)

    greet("Asha")                  # Hello Asha
    greet("Asha", "Good morning")  # Good morning Asha
    greet("Asha", message="Hi")    # Hi Asha

Invalid:
    def greet(message="Hello", name):   # SyntaxError

Warning - do NOT use a mutable default (list, dict):
    def add_item(item, items=[]):       # BAD: the same list is reused
        items.append(item)
        return items

    add_item(1)    # [1]
    add_item(2)    # [1, 2]   surprise!

    # Correct way:
    def add_item(item, items=None):
        if items is None:
            items = []
        items.append(item)
        return items


4. VARIABLE-LENGTH ARGUMENTS (*args)
- Use *args when you do not know how many positional arguments will be passed.
- Python collects the extra positional arguments into a TUPLE.
- The name "args" is a convention; the * is what matters.

Example:
    def total(*args):
        print(args)            # (10, 20, 30)
        return sum(args)

    print(total(10, 20, 30))   # 60
    print(total(5))            # 5
    print(total())             # 0

Mixing with normal parameters:
    def show(title, *items):
        print(title)
        for i in items:
            print("-", i)

    show("Fruits", "apple", "mango", "banana")

Unpacking a list into arguments when CALLING:
    nums = [1, 2, 3]
    print(total(*nums))        # same as total(1, 2, 3)  ->  6


5. KEYWORD VARIABLE-LENGTH ARGUMENTS (**kwargs)
- Use **kwargs when you do not know how many keyword arguments will be passed.
- Python collects them into a DICTIONARY (name -> value).
- The name "kwargs" is a convention; the ** is what matters.

Example:
    def profile(**kwargs):
        print(kwargs)          # {'name': 'Ravi', 'age': 20}
        for key, value in kwargs.items():
            print(key, "=", value)

    profile(name="Ravi", age=20)

Unpacking a dictionary into arguments when CALLING:
    data = {"name": "Ravi", "age": 20}
    profile(**data)            # same as profile(name="Ravi", age=20)

Using everything together - required ORDER in the definition:
    1 normal parameters
    2 default parameters
    3 *args
    4 keyword-only parameters
    5 **kwargs

    def demo(a, b=2, *args, c=3, **kwargs):
        print(a, b, args, c, kwargs)

    demo(1)                          # 1 2 () 3 {}
    demo(1, 5, 7, 8, c=9, x=10)      # 1 5 (7, 8) 9 {'x': 10}


6. RETURN STATEMENT
- return sends a value back to the caller and ENDS the function immediately.
- Code written after return (in the same path) never runs.
- If there is no return, the function returns None.
- print() only shows output; return gives a value you can store and reuse.

Example:
    def square(n):
        return n * n

    result = square(4)
    print(result)              # 16

Return ends the function:
    def check(n):
        if n > 0:
            return "positive"
        return "zero or negative"
        print("never runs")    # unreachable

No return -> None:
    def hello():
        print("Hi")

    x = hello()                # prints Hi
    print(x)                   # None

print vs return:
    def add_print(a, b):
        print(a + b)           # shows the value, but gives back None

    def add_return(a, b):
        return a + b           # gives the value back

    total = add_return(2, 3) * 10    # 50 (works)
    # add_print(2, 3) * 10           # TypeError (None * 10)


7. FUNCTIONS RETURNING MULTIPLE VALUES
- Python lets you return several values separated by commas.
- They are actually packed into a single TUPLE.
- The caller can UNPACK them into separate variables.

Example:
    def min_max(numbers):
        return min(numbers), max(numbers)

    result = min_max([4, 9, 1, 7])
    print(result)              # (1, 9)  <- a tuple
    print(type(result))        # <class 'tuple'>

    low, high = min_max([4, 9, 1, 7])    # unpacking
    print(low)                 # 1
    print(high)                # 9

Return a list or dictionary when it reads better:
    def get_user():
        return {"name": "Ravi", "age": 20}

    user = get_user()
    print(user["name"])        # Ravi

Ignoring a value you do not need:
    low, _ = min_max([4, 9, 1, 7])


COMPARISON TABLE
----------------
Type         Syntax in def         Syntax in call           Collected as
-----------  --------------------  -----------------------  -------------
Positional   def f(a, b)           f(1, 2)                  by position
Keyword      def f(a, b)           f(b=2, a=1)              by name
Default      def f(a, b=5)         f(1) or f(1, 2)          default if missing
*args        def f(*args)          f(1, 2, 3)               tuple
**kwargs     def f(**kwargs)       f(x=1, y=2)              dictionary


QUICK SUMMARY
-------------
- Positional   : matched by order.
- Keyword      : matched by name, any order.
- Default      : fallback value; put after non-default parameters.
- *args        : any number of extra positional values -> tuple.
- **kwargs     : any number of extra keyword values -> dict.
- return       : sends a value back and stops the function; default is None.
- Multiple returns : comma-separated values come back as a tuple, which you can unpack.
