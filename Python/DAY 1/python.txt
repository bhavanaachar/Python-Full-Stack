. Introduction to Python

- Python is a high-level, interpreted, general-purpose programming language.
- Python was designed to be simple and easy to read.
- It is used for web development, data science, artificial intelligence, machine learning and automation.
- Python files are saved with the .py extension.
- Python is an open-source and platform-independent language.
- Python supports object-oriented, procedural and functional programming.

2. History of Python
- Python was created by Guido van Rossum.
- Development started in 1989.
- Python was first released in 1991.
- Python 2.0 was released in 2000.
- Python 3.0 was released in 2008.

3. Features of Python
- Easy to learn and understand.
- Simple and readable syntax.
- Open-source and free.
- Dynamically typed language.
- Platform-independent.
- Supports object-oriented programming.
- Large collection of libraries and frameworks.

4. Python Syntax
Python follows a simple syntax.

Example:
print("Hello World")

- print() is used to display output.
- Python uses indentation (spaces) to define blocks of code.
- Semicolons are generally not required.
5. Comments in Python
Comments are used to explain the code. They are ignored by the Python interpreter.

1. Single-line Comment

Uses the # symbol.
# This is a commentprint("Hello")

2. Multi-line Comment

Multiple lines can be written using multiple # symbols.
# This is Python# Day 1# Learning Pythonprint("Welcome")

6. Variables in Python
- A variable is a name used to store data.
- Python does not require explicit variable declaration.
- A variable is created when a value is assigned to it.
Example:
name = "Bhavana"age = 22salary = 25000print(name)print(age)print(salary)

7. Rules for Naming Variables
- Variable names must start with a letter or underscore.
- Variable names cannot start with a number.
- Variable names cannot contain spaces.
- Variable names are case-sensitive.
- Python keywords cannot be used as variable names.
Valid names:
name = "Python"_age = 22student1 = "ABC"

Invalid names:
1name = "Python"my name = "ABC"class = 10

8. Data Types in Python
Data types define the type of value stored in a variable.
Data Type	Description	     Example
int	        Integer values	 10
float	    Decimal values	 10.5
complex	    Complex numbers	 2+3j
str	        String values	 "Hello"
bool	    True or False	  True
list	    Ordered collection	[10,20,30]
tuple	    Ordered immutable collection	(10,20,30)
set	        Unordered collection of unique values	{10,20,30}
dict	    Key-value pairs	   {"name":"ABC"}

9. Type Checking
- The type() function is used to identify the data type of a variable.

Example:
a = 10
b = 10.5
c = "Python"
print(type(a))
print(type(b))
print(type(c))


10. Input and Output in Python
Output:print()

Used to display information.
print("Hello Python")

Input:input()

Used to accept input from the user.
name = input("Enter your name: ")print("Welcome", name)

Note: The input() function returns a string by default.
