Higher-Order Functions (HOF) and IIFE


PART 1: HIGHER-ORDER FUNCTIONS (HOF)

A function is higher-order if it:
  - takes a function as an argument, or
  - returns a function, or
  - both.

1.1 Takes a function as an argument

  function repeat(n, action) {
    for (let i = 0; i < n; i++) action(i);
  }
  repeat(3, console.log);   // 0 1 2

1.2 Returns a function

  function multiplier(factor) {
    return (num) => num * factor;
  }
  const double = multiplier(2);
  double(5);   // 10

1.3 Built-in HOFs (array methods)

  const nums = [1, 2, 3, 4, 5];

  nums.map(n => n * 2);                 // [2, 4, 6, 8, 10]
  nums.filter(n => n % 2 === 0);        // [2, 4]
  nums.reduce((sum, n) => sum + n, 0);  // 15
  nums.forEach(n => console.log(n));    // prints each, returns undefined
  nums.find(n => n > 3);                // 4
  nums.some(n => n > 4);                // true
  nums.every(n => n > 0);               // true

1.4 Chaining

  const total = [1, 2, 3, 4, 5]
    .filter(n => n % 2 !== 0)
    .map(n => n * 10)
    .reduce((a, b) => a + b, 0);   // 90


PART 2: IIFE (Immediately Invoked Function Expression)
-----------------------------------------------------

A function that runs the moment it is defined.

2.1 Syntax

  (function () {
    console.log("Runs immediately");
  })();

  // Arrow version
  (() => {
    console.log("Also runs immediately");
  })();

  // With parameters
  (function (name) {
    console.log(`Hello, ${name}`);
  })("Asha");

2.2 Why use it

  1 Avoid polluting the global scope. Variables inside stay private.

  2 Create private state (module pattern):

     const counter = (function () {
       let count = 0;   // private
       return {
         increment: () => ++count,
         get: () => count,
       };
     })();

     counter.increment();
     counter.get();   // 1
     // count is not accessible from outside

  3 Run async code at the top level:

     (async () => {
       const res = await fetch("/api/data");
       console.log(await res.json());
     })();
