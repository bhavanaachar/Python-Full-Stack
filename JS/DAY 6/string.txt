WAYS TO CREATE A STRING
1. String literals (single or double quotes)

   let a = 'Hello';
   let b = "World";

2. Template literals (backticks) - support interpolation and multi-line text

   let name = "Asha";
   let c = `Hi, ${name}!`;
   let d = `Line 1
   Line 2`;

3. String() function - converts any value to a primitive string

   let e = String(123);     // "123"
   let f = String(true);    // "true"
   let g = String(null);    // "null"

4. new String() constructor - creates a String object, not a primitive (rarely recommended)

   let h = new String("hi");
   typeof h;        // "object"
   typeof "hi";     // "string"
   h == "hi";       // true
   h === "hi";      // false

5. Converting from other values

   let i = (255).toString(16);      // "ff"
   let j = [1, 2, 3].join("-");     // "1-2-3"
   let k = "ab" + 5;                // "ab5" (concatenation)


3 STATIC METHODS OF String: Static methods are called on String itself, not on a string instance.

1. String.fromCharCode()
   Creates a string from UTF-16 code units.

   String.fromCharCode(72, 105);        // "Hi"
   String.fromCharCode(65, 66, 67);     // "ABC"

2. String.fromCodePoint()
   Like fromCharCode, but handles full Unicode code points (including emojis).

   String.fromCodePoint(128512);        // "😀"
   String.fromCodePoint(72, 105);       // "Hi"

3. String.raw()
   Returns the raw string of a template literal, ignoring escape sequences.

   String.raw`C:\Users\new\table`;      // "C:\Users\new\table"
   `C:\Users\new`;                      // \n becomes a newline

   let n = 5;
   String.raw`Value:\t${n}`;            // "Value:\t5"

6. SUMMARY TABLE OF STRINGS STATIC METHODS
------------------------------------------
Here is the overview of Strings Static Methods:

Method Name              : String.fromCharCode()
Description              : Converts Unicode values (code units) into a string.
                           Accepts one or more UTF-16 code units (integers)
                           as arguments.
Syntax                   : String.fromCharCode(code1, code2, ...)
Return Type              : String

Method Name              : String.fromCodePoint()
Description              : Converts Unicode code points into a string. Supports
                           supplementary characters (e.g., emojis) by accepting
                           code points directly.
Syntax                   : String.fromCodePoint(code1, code2, ...)
Return Type              : String

Method Name              : String.raw()
Description              : Creates a raw string literal by ignoring escape
                           sequences. Typically used with tagged templates.
Syntax                   : String.raw(template, ...substitutions)
Return Type              : String

1. STRING length PROPERTY
-------------------------
length Property:
- The length property is used to determine the number of characters in a string. This includes spaces, special characters, and punctuation.
- The length property is read-only and directly gives the total number of characters in the string.
- Syntax ->

    string.length

- For Example ->

    let text = "Hello, World!";
    console.log(text.length);
    // Output: 13 (counts each character in the string)
